# XCUI Streams v3.8.9

This release fixes Search sticking to the previous query and improves subscription readiness/feedback.

## Highlights

- Search now always prompts for a fresh query when opened from the menu (issue #7).
- Validates subscription credentials before searching and reports when no data is loaded (issue #8).
- Search and catch-up show searched counts and explicit empty/error states.
- Added "Reload Subscription Data" action in Settings and Extras.
- Home screen prompts for subscription details when missing.

See the [full changelog](https://github.com/Nigel1992/plugin.video.iptvxc/blob/v3.8.9/CHANGELOG.md#version-389-2026-08-27) for details.

## Installation

Download `plugin.video.iptvxc-3.8.9.zip`, then in Kodi select **Settings → Add-ons → Install from zip file**.

The archive contains the required top-level `plugin.video.iptvxc/` directory and can be installed directly by Kodi.
