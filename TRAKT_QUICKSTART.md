# Quick Trakt Setup Guide

## Super Simple Setup (2 minutes)

### Step 1: Enable Trakt
1. **Settings** → **Trakt.tv** category
2. Enable "**Enable Trakt.tv**"
3. Enable "**Auto-Scrobble Playback**" (recommended)

### Step 2: Sign In
1. Main Menu → **Trakt.tv**
2. Select "**Sign In to Trakt**"
3. A dialog will show you:
   - URL: **https://trakt.tv/activate**
   - A code (example: **ABC-DEF-GH**)
4. Open that URL on your phone/computer
5. Enter the code shown
6. Authorize the app
7. Click **OK** on Kodi
8. Done! ✓

## Troubleshooting

**"Failed to get device code"**
- Check your internet connection
- Try again in a few seconds

**"Authorization timeout"**
- Make sure you entered the code at trakt.tv/activate
- The code expires after 10 minutes
- Try signing in again

**"Scrobbling not working"**
- Enable "Auto-Scrobble Playback" in settings
- Make sure "Enable Trakt.tv" is turned on
- Sign in to Trakt if you haven't already
